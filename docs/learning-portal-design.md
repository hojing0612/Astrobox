# AstroBox 밝은 탐구 포털 개편

2026-10-06. 사용자 제공 초중등 학습·가상실험 서비스 15개 주소를 확인하고, 탐색·계정·이용 안내를 분리하는 구조를 AstroBox의 기존 기능에 적용했다. 다른 서비스의 이미지·문구·후기·성과 수치는 가져오지 않았다.

## 화면 구조

- 주 메뉴: 탐구 홈 / 탐구 둘러보기 / 나의 탐구방 / 부모님 가이드 / 이용권.
- 상단 이용 메뉴: 도움말 / 부모 리포트 / 로그인 / 가족 계정 만들기.
- 활동 중 보조 메뉴: 로켓 / 궤도 / 자유 실험 / 별 / 시간 여행. 기존 해시 주소 유지.
- 모바일: 전체 메뉴 버튼으로 모든 페이지 접근. ESC로 닫기, 이동 후 닫기.
- 홈: 밝은 하늘색 대표 장면, 큰 시작 버튼, 주제별 바로가기, 실제 로컬 기록 요약.
- 탐구 목록: 기존 8개 활동만 분류·검색. 없는 강좌나 가짜 성과를 표시하지 않음.
- 나의 탐구방: 실제 실험 횟수·카드·최근 활동. 최근 활동은 실험 상태 복원이 아니라 해당 탐구 다시 시작.
- 계정: 로그인과 생성 화면 분리, 명시적 입력 라벨, PIN 가림·보기, 오류 안내. 기존 가족 코드 인증 API 유지.
- 이용권: 무료 탐구/미션 팩 비교 → 무료 데모 신청 확인 → 완료 → 이용 내역. 실제 PG 미연동. 서버 로그인 실패 시 몰래 로컬 이용권으로 대체하지 않음.
- 부모 리포트: 기록이 없는 경우에도 미션 팩 요청함에 접근. 신청은 이용권 페이지로 모음.

## 기술 범위와 한계

`src/portal.js`와 `portal.css`에 포털 화면을 분리했다. 물리·판정 엔진, 로켓 iframe 연출은 유지한다. 시뮬레이션은 어두운 우주 배경을 유지하고 주변 제어·안내 패널만 밝게 조정했다. 기존 마스코트·NASA 텍스처와 코드로 그린 아이콘을 사용했다.

계정 복구, 소셜 로그인, 실제 결제, 학습 효능 검증을 새로 제공하지 않는다. 기존 단일 브라우저 기록은 로그아웃 후에도 남는 구조로 안내한다. 실제 가족 계정 생성·실결제·데이터 삭제는 UI 검수에서 수행하지 않는다.

## 검증 (2026-10-06)

- `npm test`: 8개 통과. 기존 로켓 연료별 물리·궤도 기준값 4개와 검색/최근 활동/로컬 무료 신청/서버 실패 처리 4개.
- 브라우저: 데스크톱 1280px, 모바일 390×844·360×800. 주요 7개 페이지 가로 넘침 확인. 궤도 카드 장식 클래스 충돌로 생긴 모바일 넘침 수정 후 360px에서 scrollWidth=360 확인.
- 주제 ‘별·우주’ + 검색 ‘시간’ → 시간 여행 1개. 전체 탐구는 실제 활동 8개.
- 비로그인 로컬 환경에서 무료 미션 팩 신청 확인 → 0원 완료 → 이용 내역과 미션 열림 확인.
- 궤도 미션 예측 → 실행 → 설명 카드 저장 → 새 탐구방의 실험 1회·카드 1장 및 작성 내용 확인.
- 로켓 100% 연료로 발사 → 100배속 → 궤도 진입 결과 확인. 물리 엔진 변경 없음.
- 계정 로그인/생성 화면 분리·PIN password 타입·모바일 입력 레이아웃 확인. 실제 계정 생성/로그인은 이번 검수에서 수행하지 않음.
- 시간 여행·별 일생 재생 도중 홈으로 이동해 남은 애니메이션/이벤트를 해제. 2D·3D 뷰 dispose를 라우터에 연결해 이전 화면의 콜백이 새 화면을 갱신하지 않게 함.
- 브라우저 오류 로그 없음. 소형 화면 테스트는 브라우저 뷰포트 검증이며 실제 어린이 관찰이나 실물 휴대폰 성능 검증은 아님.
