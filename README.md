# AstroBox Demo

질문에서 시작해 직접 실험하고 설명하는 AI 우주 탐구 프로토타입입니다.

## Demo

- Live demo: https://astrobox-mission-demo.hojing0612.chatgpt.site
- 실행: `index.html`을 브라우저에서 열면 됩니다.

## Interaction

1. 우주 배경의 시작 화면에서 **Start mission**을 선택합니다.
2. 위성이 어떻게 움직일지 예측합니다.
3. 옆방향 속력 슬라이더를 움직여 추락, 공전, 이탈을 비교합니다.
4. 실험 결과에 따라 달라지는 AI 질문을 확인합니다.
5. 관찰 결과를 자신의 말로 설명 카드에 기록합니다.

현재 버전은 팀 내부 검토를 위한 정적 데모이며, 실제 AI 모델이나 물리 엔진 서버는 연결되지 않았습니다.

## Deployment

이 저장소의 `main` 브랜치는 Vercel과 연결되어 있으며, 변경 사항을 푸시하면 자동으로 다시 배포됩니다.
